# LP - Dr. Thiago Cerqueira

Landing Page do Dr. Thiago Cerqueira criada a partir da transcricao de onboarding e do processo `brain/LP`.

## Preview local

Com a pasta `LP` como raiz:

```powershell
python -m http.server 8123 --bind 127.0.0.1
```

Abrir:

```text
http://127.0.0.1:8123/
```

## Arquivos principais

- `index.html`: pagina navegavel.
- `styles.css`: layout responsivo.
- `script.js`: inicializacao de icones e estado do header.
- `copy-final.md`: copy consolidada da versao atual.
- `00-briefing-lp.md`: briefing derivado do onboarding.
- `01-estrategia-lp.md`: estrategia e decisoes.
- `02-wireframe-textual.md`: arquitetura da pagina.
- `04-mapa-icones.md`: mapa de icones exigido pelo brain.
- `05-pendencias-validacao.md`: pontos que precisam ser confirmados antes de publicar.
- `06-checklist-revisao.md`: checklist da primeira revisao.
- `assets.md`: inventario de assets.
